# Новый тур: «Горы Ташкента» — Амирсой, Чимган, Ходжикент и Чарвак

Частный тур на 1 день из Ташкента, до 3 гостей, трансфер от отеля.
Дата исследования: сентябрь 2026. Курс ЦБ: **1 USD ≈ 11 825 сум**.

**Вывод:** почти все продают одно и то же: «Амирсой → Чимган → Чарвак», 8–9 часов.
Отличаться можно так:
1. **Гастро-остановка по дороге**: кок-сомса (самса с зеленью) и чай в Газалкенте. Гостям это нравится, а у большинства конкурентов этого нет.
2. **Ходжикент**: тысячелетние чинары (платан ~850 лет) и петроглифы (IV–III тыс. до н.э.). Даёт туру историю, а не только виды.
3. **Ранний выезд (07:30)**: вы у гондолы Амирсоя к открытию и без очередей, а групповые автобусы приезжают позже.
4. **Обед с форелью** в горном ресторане у реки вместо «стандартного» кафе.
5. **Закат/чай на тапчане у Чарвака** в конце дня.
6. **Фото гостей**: вы знаете лучшие точки, делаете фото на их телефон. В отзывах часто хвалят именно это.

## 2. Маршрут (летний вариант, апрель–октябрь)

```
Ташкент (отель)
   │ ~60 км, 1 ч
   ▼
Газалкент ── кок-сомса, чай, фрукты (20 мин)
   │ ~35 км, 45 мин (по пути фото-стоп у плотины Чарвака, 5–10 мин)
   ▼
Амирсой ── гондола на 2290 м, прогулка наверху (2,5 ч)
   │ ~10 км, 15–20 мин
   ▼
Чимган ── обед + смотровая / конная прогулка (1 ч 45 мин)
   │ ~25 км, 30 мин
   ▼
Ходжикент ── чинары, петроглифы, по желанию канатка «Чинаркент» (40–60 мин)
   │ ~10 км, 15 мин
   ▼
Чарвакское водохранилище ── берег, тапчан, чай, по желанию лодка (1 ч)
   │ ~75 км, 1 ч 20 мин – 1 ч 40 мин
   ▼
Ташкент (отель)
```

### Расписание по времени

| Время | Что делаем |
|---|---|
| 07:30 | Встреча в отеле в Ташкенте, выезд |
| 08:30–08:50 | **Газалкент**: кок-сомса из тандыра, чай, сезонные фрукты на рынке |
| 09:20 | Фото-стоп у плотины Чарвака: первый вид на бирюзовую воду |
| 09:45–12:15 | **Амирсой**: гондола (8–10 мин подъём), прогулка по верхней станции, фото. Вы помогаете купить билеты и ждёте внизу |
| 12:30–13:30 | **Обед** в горном ресторане у Чимгана (форель, плов, шашлык) |
| 13:30–14:15 | **Чимган**: смотровая на пик Большой Чимган; по желанию конная прогулка (50–200 тыс. сум, оплата на месте) или кресельная канатка Бельдерсай (работает не всегда, чаще по выходным) |
| 14:45–15:45 | **Ходжикент**: чинары ~850 лет, петроглифы. По желанию канатка «Чинаркент» на смотровую 1680 м (100 тыс. сум) |
| 16:00–17:00 | **Чарвак**: берег, чай на тапчане, по желанию лодка/катер (в сезон) |
| 17:00 | Выезд в Ташкент |
| 18:30 | Высадка у отеля |

**Итого: ~11 часов** (из них ~4 ч 30 мин в дороге, ~230 км).
Конкуренты дают 8–9 часов. Можно продавать и **короткую версию «Классика» (8,5–9 ч)** без Ходжикента, с выездом в 08:00.

### Вариант для активных гостей: Гулкамский каньон
Вместо долгого Амирсоя (или вместо Ходжикента): пешая прогулка по каньону Гулкам к 10-метровому водопаду и изумрудным озёрцам,
**~5 км туда-обратно, 2–2,5 ч**. Нужна удобная обувь; тропа местами скользкая. Хорошо идёт как отдельная опция «+ hike».

### Зимний вариант (декабрь–март)
Порядок меняется: Ташкент → Чарвак (утренние виды) → Чимган → Амирсой (снег, лыжи/тюбинг) → Ташкент.
Гулкам зимой не предлагать. Нужны зимние шины/цепи: серпантин на Чимган обледеневает.

### Чего не делать
- Не везти иностранцев дальше Бричмуллы в сторону Пскема без проверки: это приграничная зона, может понадобиться пропуск.
- Не обещать канатку Бельдерсая: она часто не работает в будни.

GetYourGuide берёт комиссию, обычно **20–30%**. В расчёте заложено 25%.

- Для первых 10–15 отзывов можно временно снизить цену на $10–20, а после набора рейтинга поднять.

## 5. Что нужно, чтобы открыть тур на GetYourGuide

1. **Аккаунт поставщика**: supplier.getyourguide.com. Нужны юрлицо или ИП, реквизиты для выплат, документы.
2. **Проверить требования в Узбекистане**: статус туроператора/гида (аттестат гида), страховка пассажиров. Уточните в Комитете по туризму.
3. **Фото**: 8–15 своих горизонтальных фото хорошего качества (Амирсой сверху, Чарвак, чинары, кок-сомса, машина, вы с гостями).
4. **Текст объявления**: готов на английском в файле [`getyourguide-listing.md`](getyourguide-listing.md).
5. **Опции (Options) в объявлении**: Standard и All-inclusive, цена «за группу до 3».
6. **Расписание**: старт 07:30 (и 08:00 для «Классики»), ежедневно; отмена бесплатно за 24 ч.
7. **Мгновенное подтверждение** (instant confirmation): сильно поднимает продажи.
